\section{Prompts}
\label{app:prompts}
The system instructions (\cref{fig:promptsys}) precede the cached corpus and are
identical for every task; the Task A user prompt (\cref{fig:prompttask}) is
followed at run time by the manifest of document indexes and section labels;
the tagging prompt (\cref{fig:prompttag}) is sent once per item. The Task B
is-a prompt, the discovery prompt and the consolidation prompt are in the
released artefact.
