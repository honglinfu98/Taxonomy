# WWW (The Web Conference) papers on taxonomy, ontology, classification and tagging

Collected 2026-10-26 as venue-specific related work for the WWW '27 submission
(LLM-based crypto-asset taxonomy, Semantics and Knowledge track).
Venue for every entry was confirmed against the ACM DOI (10.1145/<proceedings>.<paper>).
Files are named `WWW<year> - <title>.pdf`. Most are the arXiv author versions; the
camera-ready may differ slightly in title or wording.

## How the list was built
OpenAlex sweep of all WWW main and companion proceedings 2018-2026 by DOI prefix (6,288 records),
title-filtered for taxonomy / ontology / hierarchical classification / tagging / hypernymy, then
supplemented with known WWW papers the sweep missed (e.g. TELEClass). PDFs came from arXiv where an
author version exists, otherwise from institutional repositories. Non-ML and off-topic hits
(security taxonomies, KG completion, image classification) were dropped.
